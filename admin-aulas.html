Enviar / Editar Aula — CriativaMente Academy

Pra aula nova: preencha os campos e clique em "Salvar aula". Pra editar uma aula que já existe: use o botão "Ver aulas já existentes" abaixo.

Preenche automaticamente o nome desse módulo (aparece pro aluno como título da seção). Só precisa preencher uma vez por módulo — nas próximas aulas do mesmo módulo, deixa em branco que ele não sobrescreve.

Use este botão pra módulos que já têm todas as aulas prontas e só precisam do nome corrigido — preenche "Número do módulo" e "Nome do módulo" acima, clica aqui, e pronto.

Escolha o curso e o número do módulo acima, depois clique aqui. Vai aparecer a lista das aulas já salvas nesse módulo — clique em uma pra carregar ela no formulário e editar.

Para aulas tradicionais, use o editor abaixo. Para aulas criadas como arquivo HTML completo, importe o arquivo ou cole o código no campo HTML. O HTML completo preserva a estrutura, os estilos e os scripts da aula.

⏳ Enviando imagem, aguarde...

O arquivo será armazenado como HTML da aula e exibido em um quadro isolado para impedir acesso direto à sessão da plataforma. Limite recomendado: 700 KB por aula.
