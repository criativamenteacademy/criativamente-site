# CriativaMente Admin
Aplicativo Android privado que utiliza o painel administrativo oficial via HTTPS. Login por e-mail e senha, sessão local do WebView, seleção de arquivos e navegação. Não inclui credenciais. O painel e suas permissões continuam sendo a fonte de verdade. Testar upload, auditoria, prévia, clipboard, downloads e reautenticação no aparelho antes de considerar paridade completa.
Build: Gradle 8.9, JDK 17, Android SDK 35; gradle :app:assembleDebug.
